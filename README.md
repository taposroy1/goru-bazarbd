# গরু বাজার (Goru Bazar) - আধুনিক গবাদিপশু মার্কেটপ্লেস

বাংলাদেশের প্রথম ও বিশ্বস্ত অনলাইন গরু কেনাবেচার পূর্ণাঙ্গ ডিজিটাল মার্কেটপ্লেস। উন্নত জাতের দুগ্ধবতী গাভী, কোরবানির ষাঁড় ও ব্রিডিং পশুর জন্য একটি সম্পূর্ণ নিরাপদ প্ল্যাটফর্ম।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

১. **ব্যবহারকারীর ধরন (User Roles):**
   - **সাধারণ দর্শক (Visitor):** সহজে গরু ব্রাউজ, সার্চ ও ফিল্টার করতে পারে।
   - **ক্রেতা (Buyer):** পছন্দের তালিকা, অগ্রিম বুকিং অ্যাডভান্স পেমেন্ট ও রিয়েল-টাইম অর্ডার ট্র্যাকিং।
   - **খামারি/বিক্রেতা (Seller):** প্রথম ১টি লিস্টিং সম্পূর্ণ বিনামূল্যে, এরপর আকর্ষণীয় সাবস্ক্রিপশন প্যাকেজ, বিস্তারিত ফর্ম ও বিক্রয় ড্যাশবোর্ড।
   - **সুপার অ্যাডমিন (Super Admin):** পূর্ণাঙ্গ নিয়ন্ত্রণ প্যানেল, ইউজার ম্যানেজমেন্ট, খামারি অনুমোদন, লিস্টিং এপ্রুভাল, পেমেন্ট এসক্রো ভেরিফিকেশন, অডিট লগ এবং সাইট সেটিংস।

২. **এসক্রো বুকিং অ্যাডভান্স পেমেন্ট সিস্টেম:**
   - প্রতিটি গরুর জন্য নির্দিষ্ট বা শতকরা হার অনুযায়ী বুকিং অ্যাডভান্স নির্ধারণ।
   - বিকাশ (bKash), নগদ (Nagad), রকেট (Rocket) ও ব্যাংক পেমেন্ট সিমুলেশন ও রিসিট জেনারেশন।

৩. **খামারি সাবস্ক্রিপশন ও ফ্রি লিস্টিং পলিসি:**
   - নতুন খামারিদের জন্য প্রথম ১টি গরু লিস্টিং সম্পূর্ণ ফ্রি।
   - ফ্রি লিস্টিং সীমা অতিক্রম করলে স্বয়ংক্রিয়ভাবে প্যাকেজ ক্রয়ের নির্দেশনা।

৪. **অ্যাডমিন Netlify DIST বিল্ড ও ZIP ডাউনলোড সিস্টেম:**
   - অ্যাডমিন ড্যাশবোর্ড থেকে ১ ক্লিকে Production Ready Netlify Deployment Package (.ZIP) তৈরি।
   - প্যাকেজের মধ্যে `dist/index.html`, `_redirects`, `netlify.toml`, `robots.txt`, `sitemap.xml`, `assets/`, `README_NETLIFY.md` ইত্যাদি স্বয়ংক্রিয়ভাবে সংরক্ষিত থাকে।

## 🐙 GitHub রিয়েল-টাইম অটো-সিঙ্ক গাইড (GitHub Auto-Sync)

আপনার এই ওয়েবসাইটের সকল পরিবর্তন সাথে সাথে GitHub-এ সিঙ্ক রাখার জন্য ৩টি সুনির্দিষ্ট ব্যবস্থা রয়েছে:

### পদ্ধতি ১: Google AI Studio-র অফিসিয়াল "Export to GitHub" (সবচেয়ে সহজ)
১. AI Studio-র উপরের ডানদিকের মেনুতে **"Export"** বা **"Push to GitHub"** আইকনে ক্লিক করুন।
২. আপনার GitHub একাউন্ট (`taposroy616`) এবং রিপোজিটরি (`goru-bazar`) সিলেক্ট করুন।
৩. এরপর থেকে AI এর মাধ্যমে যখনই কোনো কোড বা ফাইল পরিবর্তন করবেন, তা সাথে সাথে GitHub-এ নতুন কমিট হিসেবে জমা হয়ে যাবে।

### পদ্ধতি ২: অ্যাডমিন ড্যাশবোর্ড থেকে লাইভ ডেটাবেস অটো-সিঙ্ক (In-App REST API)
১. অ্যাডমিন ড্যাশবোর্ডে গিয়ে **"GitHub সিঙ্ক ও অটোমেশন"** ট্যাবে যান।
২. আপনার GitHub Personal Access Token (PAT) ইনপুট দিয়ে **"স্বয়ংক্রিয় ব্যাকগ্রাউন্ড অটো-সিঙ্ক"** অন করে দিন।
৩. সাইটে নতুন গরু লিস্টিং, বুকিং অর্ডার বা সেটিংস পরিবর্তন হওয়া মাত্রই GitHub-এর `data/database.json` ও `src/data/marketplace-data.json`-এ সাথে সাথে পুশ হয়ে যাবে।

### পদ্ধতি ৩: লোকাল গিট টার্মিনাল কমান্ড (CLI Push)
```bash
git remote add origin https://github.com/taposroy616/goru-bazar.git
git branch -M main
git push -u origin main
```

## 🌐 Netlify ডিপ্লয়মেন্ট গাইড (Netlify Deployment)

### পদ্ধতি ১: অ্যাডমিন ড্যাশবোর্ড ড্র্যাগ-অ্যান্ড-ড্রপ (সবচেয়ে সহজ)
১. অ্যাডমিন ড্যাশবোর্ডে প্রবেশ করুন: **“Netlify DIST বিল্ডার”** ট্যাবে যান।
২. **“Build Website”** বাটনে ক্লিক করুন।
৩. বিল্ড সম্পন্ন হলে **“Download DIST (ZIP)”** বাটনে ক্লিক করে ফাইলটি ডাউনলোড করুন।
৪. ZIP ফাইলটি আনজিপ করুন এবং ফোল্ডারটি সরাসরি [Netlify Drop](https://app.netlify.com/drop)-এ ছেড়ে দিন।

### পদ্ধতি ২: Git রিপোজিটরি ও CLI দিয়ে
প্রজেক্টে ইতিমধ্যে `netlify.toml` এবং `public/_redirects` ফাইল যুক্ত রয়েছে।
```bash
npm install -g netlify-cli
netlify deploy --prod --dir=dist
```
